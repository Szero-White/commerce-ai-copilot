# Interview demo script (6–8 minutes)

Setup: `python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`, open http://127.0.0.1:8000. LLM is off unless you configured it; **say so at the start**.

1. **Framing (30 s).** "Synthetic furniture and print-on-demand data. I wanted to practise the parts of an AI feature that fail in practice: bad retrieval, unsupported claims, silent fallbacks. The LLM path is mock-tested, and I also ran it once against a hosted Gemini free-tier model as a small smoke test; I can show you exactly what that did and did not prove."
2. **Trợ lý RAG (1 min).** Ask "Bàn Oak 120 kích thước bao nhiêu?" → point at the source `PRD-101` and the answer-mode label "Trích xuất tài liệu" (the raw code `extractive_demo` is in the "Mã kỹ thuật" detail line): "retrieval with citations, not generation."
3. **Refusal (1 min).** Ask "Hôm nay thời tiết thế nào?" and "Có giảm 5% không?" → "Không đủ bằng chứng" (`no_evidence`). Explain the relevance gate (IDF coverage, matched words must be near each other, domain synonyms, accent-aware, numbers always checked) and show `tests/test_retrieval_gate.py`.
4. **Soạn nháp quảng cáo (1 min).** Generate a draft, then type the audience `giảm 90% hôm nay` → the offer is not echoed (`audience_used: false`). Explain `safe_marketing_copy` and why it is a blocklist, not proof.
5. **Phân loại hỗ trợ (1 min).** `My personalized mug arrived damaged. Can I get a refund?` → intent, priority, policy evidence, human review. "Deterministic on purpose; not an agent."
5b. **Natural questions and follow-ups (1.5 min, v4).** Ask "Có bàn gì?" (it used to abstain: "bàn", "bạn" and "bán" all fold to `ban`) → desk products. Then "Cho mình xem các sản phẩm đang bán" → numbered list; "Cái thứ hai giá bao nhiêu?" → the second one, and the answer says which product it understood. Ask "Nó giá bao nhiêu?" right after the list → it asks which one (numbered options) instead of guessing. Ask "Có món nào dưới 500 nghìn không?" → the comparison is computed from the documents' numbers; show that an unverifiable item would be flagged, not claimed. Ask "Bàn Oak 120 còn hàng không?" → refused: no document states a stock figure.
6. **Đánh giá chất lượng (1 min).** Show [EVALUATION_REPORT.md](EVALUATION_REPORT.md) section 6: baseline vs final on dev, a holdout locked by hash, and fresh products imported after a freeze. Say the unseen results (Hit@3 14/25 holdout, 12/19 fresh) **missed the 80% target** and why; legacy 31/31 and 32/33 are tuned-on sets and only prove no regression.
6b. **New knowledge without code (1 min, v4).** `python -m scripts.ingest data\eval_v4\fresh\fresh_products.csv`, ask "Shop bán ghế công thái học không?", then change a price and re-import, delete the source, and run `python -m scripts.check_index`. Say: BM25 is current immediately, vectors are not (manual indexing), there is no real-time sync.
7. **Code walk (2 min).** `app/evidence.py` (numbers, negation: "not eligible for return" cannot be answered "you can return"), `app/ollama.py` (loopback only, `num_ctx`, error handling), a failing-then-passing test such as `tests/test_negation_claims.py`.
8. **Limits and next step (30 s).** "The live smoke (before v4) shows the pipeline works on 3 answers and 1 agent task; it is not an accuracy number, and I have not re-run a real LLM since the v4 changes. I did run real embeddings on the dev questions: the right document came first 8 times out of 8, but no safe threshold could admit documents by meaning, so hybrid is off. Next: a larger and independently written holdout, a faithfulness review of LLM answers, and more documents." (Optionally show `docs/LIVE_EVALUATION_GEMINI.md`.)

**Likely questions.** *Why not LangChain/LangGraph?* The loop is 3 steps with a whitelist; a framework would hide the parts I wanted to test. I can use them; I have not shipped with them. *Does the guard stop hallucination?* No: numbers, listed promises, negated policies and citation IDs only. *Is the agent real?* The loop and whitelist are real and mock-tested, and it ran once end to end on Gemini: two read-only tool calls, a cited answer that passed the validator. One task, so I do not claim reliability. *What did the live run find?* My validator wrongly rejected a correct answer because it read the digits of a document ID as a number; I fixed it generally and added tests.
